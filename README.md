# FlashTrans

极速划词 / 截图翻译工具（Windows）。按一个键，译文即现。

> **v2 全新重写**：Tauri 2 + Rust，本体轻、启动即用。
> 旧版（v1，Python/PySide6）代码保留在 [`legacy-v1`](../../tree/legacy-v1) 分支。

## 功能一览

| 热键 | 功能 |
| --- | --- |
| `F1` | 划词翻译 — 选中文字后按，弹窗即现译文 |
| `F2` | 打字翻译 — 输入即译，回车把译文粘贴回原窗口 |
| `F3` | 截图翻译 — 框选屏幕 → OCR → 翻译；可复制截图 / 贴图置顶 |
| `F4` | AI 对话 — 本地大模型或自备 API |
| `F5` | 主窗口 — 双栏翻译台 + 设置 |

热键均可自定义。

## 翻译引擎（按需选择，可共存）

- **GGUF 大模型**（单文件）— 原生推理，翻译 + 对话，开箱即用
- **NLLB-200 / Opus-MT**（CTranslate2）— 200 语种 / 中英极速，开箱即用
- **在线 API**（BYOK）— 任意 OpenAI 兼容接口（DeepSeek、Kimi、硅基流动等）

本体与模型分离：安装包很小，模型按需下载，在设置里点选即可使用，
无需安装 Python 或任何运行环境。

## 隐私

- 本地模型翻译全程离线，文本不出本机
- API 模式仅向你自己填写的服务商发送待翻译文本；Key 仅存本机、不上传
- 无遥测、无统计、无自动联网

## 更新日志

### v2.3.0（2026-08-08）

这一版专治 v2.2.0 的截图翻译：**译文会凭空少内容**、**覆盖上去的排版是乱的**、**按 F3 屏幕会闪**。

- **覆盖排版重做** — 现在分两种，默认「自动」按文字密度选：成段的文档**整块重排**（整片统一字号、保留分段），零散文字（字幕、按钮、标签）**逐段贴回原处**。
  原位模式下全图字号统一，方块塞不下会先向周围的空白生长，仍然塞不下才整块重排 —— 不会再一块大一块小，也不会把译文裁掉半句。
  覆盖时按 `Tab` 随时换排版，设置里也能固定成「原位」或「整块」
- 修复：**一句话被切成好几段各翻各的** — 识别引擎常把同一行切成几个检测框，此前每个碎框都当成独立段落单独送去翻译，既丢上下文（「有道」被当成语种译成 Yiddish）也让覆盖层散成一堆互相压住的小方块。现在先把碎框并回「行」再并成「段」，分栏排版也能各归各段。段落判定改用「上沿到上沿」的行距并和整图的中位行距比，不再被 OCR 框高的抖动带偏（此前正文会被拦腰劈成两段、大字标题会被并进正文首段）
- 修复：**截图里整行整行地漏字** — 识别引擎内部会把整图缩到固定大小，密集长文的正文只剩十几像素高，一段里常常整整少认一行。漏一行还会连带把行距撑成两倍、让段落从中间劈开，所以看起来是「少了一句话又多出一个段落」。现在检测到行距异常就自动切条重认一次并取并集，实测 18 行的长文从 16 行补齐到 18 行；字幕、短句、聊天气泡这类不触发，速度不变
- 修复：**NLLB / Opus-MT 会安静地吞掉半句** — 遇到破折号或三四个逗号并列的长从句时，译着译着就少一半（不报错、不截断，纯粹少内容，很难发现）。调了切句粒度，实测四段英文原文里破折号后的内容从 100% 丢失变为全部完整译出；万一模型对某一块吐空，也改为保留原文而不是让它消失
- 修复：**按 F3 时屏幕突兀地闪一下**。三处原因：截屏每次都先试 DXGI，静止桌面要空等最多 500ms 且会惊动桌面合成（改为 GDI 优先，只有截到全黑才退回 DXGI）；框选窗口一显示就先亮一帧**上一次**的截图 —— 窗口隐藏期间 WebView 不合成，图层里存的还是旧画面，所以换个页面再截会「先闪回上一个页面」，同一页面连着截反而不闪（改为收起前清空底图、新图解码完才现身，覆盖窗口同理）；全屏 PNG 改用快速压缩
- 修复：截图结束时那片阴影「从大缩到小」 — 是 Windows 给窗口隐藏加的 DWM 过渡动画，已对框选 / 覆盖 / 弹窗这三个瞬时窗口关掉
- 弹窗流式输出时不再每来一个字就改一次窗口大小 —— 置顶 + 毛玻璃窗口每次改尺寸都要让 DWM 重做一遍合成，一秒几十次会拖慢整个桌面的鼠标指针（有用户反馈「鼠标卡出两个」）

已知问题：框选时如果紧贴着文字拖，**首行或末行可能被漏掉**（识别引擎会丢弃贴着图像边缘的文字）。这种漏行不会让行距出现异常，上面的切条补偿发现不了，**框选时请留一点余量**。

### v2.2.0（2026-08-01）

继续按反馈补功能：

- **开机自启只进托盘** — 开机启动那一次不再弹出主窗口，只驻留托盘；设置里新增「开机自动启动」开关（与安装包里的勾选项是同一处，随时可开关）
- **不再多开** — 重复打开只把已有窗口叫到前台。此前多开出来的进程抢不到全局热键，等于开了一个用不了的窗口
- **双向自动切换** — 打开后，识别到的文字正好是目标语言时自动译回源语言（设「中→英」，遇到英文就译成中文）。靠字符判断语言，中 / 日 / 韩 / 俄 / 阿 / 泰 与拉丁字母之间有效，英↔法这类同属拉丁字母的分不出
- **对话 / 纠错模型可单独指定** — 翻译用 NLLB / Opus-MT 时，可以另外指定一个 .gguf 大模型专跑 F4 对话与 OCR 纠错，翻译仍走原来的模型
- **截图翻译：译文原位覆盖** — 译文直接盖在框选区域的原文上，空格键对照原文、Esc 关闭；悬浮弹窗照常出现，复制原文 / 译文 / 追问 / 贴图都还在。设置里开关
- **自定义 OCR 模型** — 系统没装语言包的语种（韩语、俄语…）可以自己添加 RapidOCR / PP-OCR 格式的 ONNX 识别模型，点选即用；默认仍是内置中英 RapidOCR + 系统 OCR
- **截图框选看得见指针了** — 十字光标改成白线 + 深色描边，纯黑背景上也能一眼找到
- **主界面 Enter 直接翻译** — Shift + Enter 换行（Ctrl + Enter 仍然可用）
- 修复：界面缩放选「大 / 特大」时，底部的翻译、复制按钮会被挤出窗口，点不到也看不见
- 修复：标题栏的最大化按钮一直无效（缺少窗口权限声明）
- 热键注册改为只增删变化的那几个键，不再每次保存设置都全量注销重注册

### v2.1.0（2026-07-12）

本次更新全部来自视频评论区的反馈：

- **模型可移除** — 本地模型列表每个模型都能点 🗑 从列表移除（只是不再显示，不删磁盘文件），列表底部可一键恢复；添加错的失效路径同样能移除
- **API 多预设** — 可保存多套 OpenAI 兼容 API 配置并随时切换（设置面板点选，或主界面右下角快速切换）；旧配置自动成为第一条预设
- **领域提示词** — 给大模型 / API 翻译附加自定义领域要求（如医学、法律、游戏），支持多条预设、主界面快速切换；划词 / 打字 / 截图 / 主窗口翻译全部生效。NLLB / Opus-MT 为专用翻译模型，不支持指令，故不适用
