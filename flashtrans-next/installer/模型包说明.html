FlashTrans 模型使用说明

划词 / 截图 · 极速翻译。装完这一步，选好翻译引擎就能用。

?FlashTrans 需要什么

FlashTrans 本体很轻，不自带翻译模型。翻译能力来自你二选一（也可都配）的引擎：

  • 本地离线模型 —— 免费、私密、离线可用，适合快速查词看句。
  • 在线 API（自备 Key） —— 质量最好、要联网要 Key，适合追求“信、达、雅”的整段翻译。

定位小抄：离线小模型 = 即时 / 免费 / 私密的速查；API = 要精译时插个 Key。

1用在线 API（最简单，推荐先试）

打开主窗口 → 右上角 ⚙ 设置 → 「翻译引擎」选在线 API，填写任意 OpenAI 兼容接口：

  • Base URL、Model、API Key —— 支持 DeepSeek、Kimi、硅基流动、OpenAI 等。
  • 点「测试连接」通过后保存即可。Key 只存在你本机，不上传。

无需下载任何模型文件，配好即用。

2用本地离线模型

第一步：拿到模型。从作者提供的网盘下载模型包（视频简介 / 主页有链接）：

📦 网盘地址（作者填写）：在此粘贴你的网盘链接

第二步：放到 FlashTrans 能找到的地方。两种方式任选：

  1. 设置 → 「本地模型」→ 点 打开默认文件夹，把整个模型（文件夹或 .gguf 文件）放进去，回设置点刷新。
  2. 或直接点 ＋ 添加 .gguf 大模型 / ＋ 添加模型文件夹，从任意位置（含网盘下载目录）选中模型 —— 无需搬动文件。

第三步：在模型列表里点选它，右上角徽章显示「本地 · …」即生效。点每个模型右侧 ✎ 还能自定义名称备注。

3模型类型 & 兼容性

类型长相运行要求
GGUF 大模型
开箱即用		 单个 .gguf 文件 原生推理，无需任何额外环境。可做翻译，也能进 F4 对话。
Opus-MT（中英）
开箱即用		 文件夹，内含 model.bin 轻量中英互译、速度最快。由随包安装的翻译引擎驱动，无需任何额外环境。
NLLB-200
开箱即用		 文件夹，内含 model.bin 200 语种离线翻译。同样无需任何额外环境。
三类模型都开箱即用：下载后放进默认文件夹（或用「添加模型」直接选中），在列表里点一下即可开始翻译。 不确定选哪个？只翻中英选 Opus-MT（最小最快）；要多语种选 NLLB； 想要翻译质量更高、还能对话选 GGUF 大模型（对电脑性能要求也更高）。

4常用快捷键

键功能
F1划词翻译（选中文字后按）
F2手动输入翻译
F3截图框选 → OCR 识别 → 翻译
F4AI 对话窗（需 GGUF 或 API）
F5打开 / 唤起主窗口

快捷键都可在 设置 → 全局热键 里自定义。
